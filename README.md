# Classic Cleaner OSS

Un cleaner leggero, trasparente e con filosofia classica.  
Progettato per offrire pulizia del sistema senza bloat, senza telemetria e senza funzioni inutili.

---

## 📌 Filosofia del progetto

Classic Cleaner OSS nasce con questi principi:

- **Leggerezza** — nessun modulo pesante, nessuna dipendenza inutile.
- **Trasparenza** — ogni funzione è chiara, documentata e comprensibile.
- **Controllo all’utente** — niente automatismi invasivi, niente processi nascosti.
- **Pulizia reale** — solo ciò che serve davvero, senza marketing.
- **Open‑Source** — codice pubblico, verificabile e migliorabile dalla community.

---

## 🧹 Funzionalità previste

- Pulizia cache di sistema  
- Pulizia file temporanei di Windows  
- Pulizia log non necessari  
- Pulizia residui degli aggiornamenti  
- Pulizia cartelle temporanee utente  
- Analisi dello spazio occupato  
- Modalità “Classic” (solo funzioni essenziali)  
- Modalità “Extended” (funzioni avanzate opzionali)
