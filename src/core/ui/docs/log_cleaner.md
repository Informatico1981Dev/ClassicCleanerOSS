# ClassicCleanerOSS - LogCleaner (Draft)

## Obiettivo
Il modulo LogCleaner si occupa della pulizia dei file di log generati dal sistema o dalle applicazioni.

## Stato attuale
- Implementazione base completata.
- Il modulo esegue una simulazione di pulizia.
- Output informativo tramite Logger.

## Funzioni previste
- Rilevamento dei file di log.
- Pulizia dei log obsoleti.
- Pulizia dei log di errore.
- Pulizia dei log delle applicazioni.
- Report finale con numero di file rimossi.

## Note
La logica reale verrà implementata dopo la definizione completa dei percorsi e dei tipi di log supportati.
